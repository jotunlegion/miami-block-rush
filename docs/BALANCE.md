## Formulas

| What | Formula |
|---|---|
| Upgrades (per level 0..3) | engine top +6%, gearbox top +2.5% & accel +5%, turbo accel +12%, tires hill +0.06 & launch +0.04, suspension air -5%, chassis armor +15% |
| Pace (px/s) | top x (1+0.00016(accel-300)) x (1+0.42(launch-1.3)) x (1+0.1 clamp(hill-0.56,0,0.3)) x (1+0.08 clamp((armor-120)/140,-0.5,1)) x (1+0.1 clamp(1-air,0,0.3)) |
| Rating | (pace - 90) x 5 |
| Upgrade price | base x (0.5 + car value / 10 000), bought level by level directly |
| Part price | base x (0.6 + car value / 25 000) |
| Level cash | bags and finish bonuses x (1 + 0.02 (level - 1)) |
| Income per level | earned per attempt / win rate 0.7; earned = min(5300, 2500 + 90 L) x cash |
| Boss race | 1 vs 1, first to the finish wins and takes the car |
| Beatable | player pace >= need = boss pace x boss skill |
| Challenge rule | the rival only takes a bet from a car worth at least the previous rival car |
| Blacklist value | set so tuning the pink slip to the next rival costs 80% of the cash on hand at that gate |

Pace was fitted on a fixed test track driven by the real car physics (no building): lap time scales as 6750 / top; accel 200 -> 700 is -7%, launch 1.3 -> 1.6 is -11%, hill 0.56 -> 0.75 is -2.5%. Income per attempt and win rate were measured with the AI builder standing in for an average player, 10 races per level.
